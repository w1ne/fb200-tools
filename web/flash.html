Install and update

Put the open firmware on your FB200, or update it, from this page. Everything runs in your browser. Nothing is uploaded.

At your own risk. Tested on one pedal with stock firmware V1.0.1. The pedal's own update mode (hold A+D while you plug in USB) is never overwritten, so you can always go back to the stock firmware. Disclaimer.

Writing to the pedal. Do not unplug it and do not close this tab.

  1. Check the browser

    Linux: allow USB access

    Add this udev rule, then unplug and plug in the pedal:

    # /etc/udev/rules.d/70-fb200.rules
SUBSYSTEM=="usb", ATTR{idVendor}=="34db", ATTR{idProduct}=="800f", MODE="0666"
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="34db", MODE="0666"
SUBSYSTEM=="usb", ATTR{idVendor}=="0483", ATTR{idProduct}=="5703", MODE="0666"
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="0483", MODE="0666"

    Then run sudo udevadm control --reload && sudo udevadm trigger. The USB console also needs your user in the dialout (or uucp) group: sudo usermod -aG dialout $USER, then log out and in.

    Loading…

  3. Choose what to do

  4. First install

    a. Choose the official firmware file

    Choose the official FB200 firmware file from FLAMMA, for example FB200_V1.0.1.mr. It supplies the pedal's loader and the stock sound data (amp models, cab IRs, tone stack, drum rhythms). This site does not include them. The file stays on your computer: this page reads it in the browser and never uploads it.

    b. Start the pedal in update mode

    1. Unplug the USB cable from the pedal.
    2. Press and hold footswitches A and D.
    3. Plug in the USB cable while you hold them. Then release them.
    4. Press Connect. Choose the device in the list and press Connect there.

    c. Write the firmware over USB

    1. The pedal restarts by itself into the recovery stage. Do not unplug it.
    2. Wait about 5 seconds.
    3. Press Connect. Choose the FB200 port in the list.
    4. The page writes the sound data, then the firmware. Then the pedal restarts.

  5. Update

    1. Plug the pedal into this computer and switch it on. No button combo is needed.
    2. Press Connect. Choose the FB200 port in the list.
    3. The page writes the firmware. The pedal restarts.

    Sound data missing?

    The amp models, cab IRs and drums come from the stock firmware file. If the pedal has no sound data, choose the official FB200 firmware file (for example FB200_V1.0.1.mr). It stays on your computer.

  6. Back to the stock firmware

    This puts the official FLAMMA firmware back on the pedal, unchanged. Your presets, settings and user IRs are in a separate flash area: they survive. You can come back to the open firmware later with First install.

    a. Choose the official firmware file

    b. Start the pedal in update mode

    1. Unplug the USB cable from the pedal.
    2. Press and hold footswitches A and D.
    3. Plug in the USB cable while you hold them. Then release them.
    4. Press Connect. Choose the device in the list and press Connect there.

  7. Done

    The pedal runs the open firmware. The display shows your current preset, for example P0C.

    To update later, open this page again and choose Update. No button combo is needed.
